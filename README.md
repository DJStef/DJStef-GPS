# DJStef GPS

Appli GPS Android : carte OpenStreetMap, recherche, itinéraires voiture/vélo/marche avec guidage vocal,
alertes radars (fixes officiels data.gouv.fr + signalements des utilisateurs).

- APK : onglet Releases (compilé automatiquement à chaque push).
- Serveur de signalements : dossier `worker/` (Cloudflare Worker + KV). L'URL se règle dans l'appli
  (appui long sur le numéro de version, en bas à droite).
